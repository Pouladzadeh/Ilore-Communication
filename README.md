# Ilore Communication

A web-based communication application that combines AI-powered voice assistance with customizable avatar creation and picture-based card communication. Ilore helps users express themselves through multiple communication modes.

## Features

### 🎤 AI Voice Helper
- Real-time speech recognition and processing
- Voice-to-text conversion for building messages
- Interactive microphone interface for hands-free communication

### 🎨 Avatar Creator
- Multi-step avatar customization interface
- Personalize your voice helper's appearance
- Step-by-step guided creation process

### 🗣️ Communication Modes
- **AI Voice Helper**: Speak naturally and get word suggestions
- **Picture Cards**: Visual communication using image-based cards
- **Message Builder**: Compose messages by selecting cards and voice suggestions

### 📱 Responsive Design
- Mobile-friendly interface
- Touch-optimized controls
- Works across all modern browsers

## Pages

- **Home** (`index.html`) - Landing page with hero section and introduction
- **Product** (`product.html`) - Main communication interface with avatar prompt and message builder
- **Avatar Creator** (`avatar-step1.html`, `avatar-step2.html`, `avatar-step3.html`) - Multi-step avatar customization
- **Contact** (`contact.html`) - Support and contact information
- **Saved Avatar** (`saved-avatar.html`) - View and manage saved avatar configurations

## Styling

- `website.css` - Main stylesheet for landing and contact pages
- `styless.css` - Application interface styles for product pages

## Media

- Located in `img/` directory with cartoon robot and app illustrations
- SVG graphics for UI components and icons

## Getting Started

1. Clone the repository
2. Open `index.html` in your web browser
3. Navigate through the application using the menu
4. Create a custom avatar or start using the message builder
